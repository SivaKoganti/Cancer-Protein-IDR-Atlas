# PLOS Portal Paste Script

Use this as a direct, sequential submission runbook for PLOS Computational Biology.

## Pre-Flight (Do Before Opening Portal)

1. Keep these files open side-by-side:
   - SUBMISSION_PORTAL_TEXT_PACK.md
   - SUBMISSION_PORTAL_FIELD_ORDER.md
   - MANUSCRIPT.md
2. Confirm you are uploading the latest manuscript PDF and figure set.
3. Confirm corresponding-author metadata is available for direct entry in the portal.

## Screen-by-Screen Entry

1. Article Type
   - Select: Research Article (or journal-equivalent primary article type).

2. Manuscript Title
   - Paste from SUBMISSION_PORTAL_TEXT_PACK.md -> Manuscript Title.

3. Abstract
   - Paste manuscript abstract from MANUSCRIPT.md.

4. Author Summary
   - Paste from SUBMISSION_PORTAL_TEXT_PACK.md -> Author Summary.

5. Significance Statement (if shown)
   - Paste from SUBMISSION_PORTAL_TEXT_PACK.md -> Significance Statement.

6. Keywords
   - Paste from SUBMISSION_PORTAL_TEXT_PACK.md -> Suggested Keywords.

7. Authors and Affiliations
   - Enter full author order.
   - Enter all affiliations.
   - Mark corresponding author.
   - Enter corresponding-author email/address.
   - Add ORCID IDs if requested.

8. Funding Information
   - Paste from SUBMISSION_PORTAL_TEXT_PACK.md -> Funding Statement.
   - Current approved text: This work received no specific external funding.

9. Competing Interests
   - Paste from SUBMISSION_PORTAL_TEXT_PACK.md -> Competing Interests Statement.

10. Data Availability
   - Paste from SUBMISSION_PORTAL_TEXT_PACK.md -> Data Availability Statement.

11. Cover Letter
   - Paste from SUBMISSION_PORTAL_TEXT_PACK.md -> Cover Letter.
   - Keep confidential-review handling note exactly as written.

12. Suggested/Excluded Editors and Reviewers (if prompted)
   - Enter according to your internal submission plan.

13. File Uploads
   - Upload manuscript PDF.
   - Upload figure files and supplementary files per portal prompts.
   - Ensure filenames and numbering match manuscript references.

14. Additional Questions / Declarations
   - Answer according to institution and journal policy.
   - Do not alter already synchronized funding/conflict/data text.

## Final Validation Gate (Before Clicking Submit)

1. Title exactly matches text pack.
2. Author Summary exactly matches text pack.
3. Data Availability statement exactly matches text pack and manuscript.
4. Competing Interests statement exactly matches text pack and manuscript.
5. Funding statement exactly matches text pack and manuscript.
6. Cover letter includes confidential-review handling language.
7. Author list/affiliations/corresponding-author details are complete and correct.
8. Uploaded manuscript is the latest build.
9. Figure numbering in uploaded assets is consistent through Figure 9.

## Fast Source Map

3. Manuscript abstract and full text: MANUSCRIPT.md
