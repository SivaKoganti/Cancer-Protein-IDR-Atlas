INSTRUMENTATION & METHODS
================================================================================

Instrument Details:
  - Type: Ubbelohde Capillary Viscometer
  - Capillary Diameter: 0.50 mm
  - Viscometer Class: Type I (for routine measurements)
  - Calibration Constant: 0.00397 cSt²/s (certified)
  - Marker Separation: 2.00 cm (length of timing section)
  - Bulb Volumes: Upper 10 ml, Lower 1 ml
  - Material: Borosilicate glass

Temperature Control:
  - Water Bath: Thermostat-controlled to ±0.1°C
  - Reference Temperature: 25.0 ± 0.1°C
  - Pre-equilibration Time: 15 minutes minimum
  - Bath Fluid: Distilled water with antifoam agent

Sample Preparation:
  - Protein Concentration: 0.1–10 mg/ml in PBS
  - Viscometer Cleaning: Sequential rinses (ultrapure water, ethanol, acetone)
  - Sample Volume: 1.0 ml per measurement
  - Degassing: 5 min in ultrasonic bath before measurement
  - Equilibration: 5 min at 25°C before timing

Measurement Protocol:
  - Flow Time Measurement: Steel ball or gravity timer
  - Timing Precision: ±0.01 second
  - Number of Runs per Sample: 2 (average used)
  - Acceptable Variation: <1% between runs
  - Solvent Reference (PBS): Measured before and after each sample set
  - Temperature Re-check: After every 5 samples

Calculations:
  - Viscosity: η = η₀ × (ρt / ρ₀t₀) [using density correction]
  - Specific Viscosity: ηsp = (η - η₀) / η₀
  - Reduced Viscosity: ηred = ηsp / c
  - Intrinsic Viscosity [η]: Extrapolated from Huggins plot to c→0
  - Relative Viscosity: ηrel = η / η₀ = 1 + ηsp

Data Analysis:
  - Plotting: Origin Pro 2021, Microsoft Excel
  - Curve Fitting: Huggins equation (ηred = [η] + k'ₕ[η]c)
  - Extrapolation: Linear regression to zero concentration
  - Statistical Analysis: SPSS 27.0, R 4.1.2
  - Error Propagation: Gaussian error analysis using SD of replicates
