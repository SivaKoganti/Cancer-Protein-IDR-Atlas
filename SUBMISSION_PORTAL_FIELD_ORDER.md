# Submission Portal Field Order

Use this page as a final, linear portal-entry checklist.

## Go/No-Go

- Scientific package: READY
- Compliance text package: READY
- Remaining manual task: enter author identities/affiliations/contact details in portal metadata fields

## Portal Entry Sequence

1. Manuscript Title
   - Source: SUBMISSION_PORTAL_TEXT_PACK.md -> Manuscript Title

2. Cover Letter
   - Source: SUBMISSION_PORTAL_TEXT_PACK.md -> Cover Letter
   - Include confidential-review handling language exactly as written.

3. Author Summary
   - Source: SUBMISSION_PORTAL_TEXT_PACK.md -> Author Summary

4. Significance Statement
   - Source: SUBMISSION_PORTAL_TEXT_PACK.md -> Significance Statement

5. Data Availability Statement
   - Source: SUBMISSION_PORTAL_TEXT_PACK.md -> Data Availability Statement

6. Competing Interests Statement
   - Source: SUBMISSION_PORTAL_TEXT_PACK.md -> Competing Interests Statement

7. Funding Statement
   - Source: SUBMISSION_PORTAL_TEXT_PACK.md -> Funding Statement
   - Current text: This work received no specific external funding.

8. Keywords
   - Source: SUBMISSION_PORTAL_TEXT_PACK.md -> Suggested Keywords

9. Handling Editor Notes (if field exists)
   - Source: SUBMISSION_PORTAL_TEXT_PACK.md -> Optional Notes For Handling Editor

## Manual Metadata You Must Enter In Portal

1. Full author list in the correct order
2. All affiliations
3. Corresponding author name, email, and address
4. ORCID identifiers (if required by portal)
5. Funding IDs/grants only if applicable; otherwise keep no-external-funding declaration

## Consistency Gate Before Submit

1. Data availability text in portal matches manuscript wording exactly
2. Competing interests text in portal matches manuscript wording exactly
3. Funding text in portal matches manuscript wording exactly
4. Cover letter includes confidential-review data/code handling note
5. Uploaded manuscript and figures correspond to the latest submission PDF (through Figure 9)

## Source Files

- Primary copy-paste text pack: SUBMISSION_PORTAL_TEXT_PACK.md
- Submission readiness checklist: SUBMISSION_PACKAGE.md
- Main manuscript: MANUSCRIPT.md
